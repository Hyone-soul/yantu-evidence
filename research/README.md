# 预置公开资料

`public-depth-excerpts.json`用于新数据库首次启动，只载入公开院校资料的核验摘录、字段位置和历史汇总。它不是完整原文缓存，也不包含运行凭据或原始API响应。

资料采集核对时间截至2026年11月6日，默认当年招生为2027年；历史记录为2024—2026年，重点是南京邮电大学与北京工商大学的计算机相关专业。其他学校可能只有部分字段或检索线索，记录数量不表示完整覆盖。

文件中每项来源保留原网址、招生年度、保存时间及片段定位。原文有缺失、适用范围不清楚或无法可靠提取时保留状态，不据此补齐人数或推算录取难度。内置成绩数据只保留汇总和原文位置，不附个人名单。个人经历原文与本机用户核对历史没有随仓库发布。

引用摘录与招生数据的权利归原发布单位，项目代码许可证不转授这些材料的版权。它们用于说明来源、数据结构及核对过程；报考时请回到相应年度的官方原文确认。再次搜索或更新可能产生接口费用，浏览预置资料不调用付费接口。
